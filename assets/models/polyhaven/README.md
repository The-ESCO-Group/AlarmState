# Poly Haven architectural models

These browser-ready glTF assets are public-domain CC0 models downloaded from
[Poly Haven](https://polyhaven.com/) through its public API.

- `modular_factory_facade`: worn brick, concrete, steel door, loading-bay,
  window, and trim modules used by the Plant 7 administration building

The project uses the 1K glTF package to preserve physically based materials
while keeping download and GPU memory costs appropriate for the browser game.
