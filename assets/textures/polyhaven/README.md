# Poly Haven PBR textures

These 1K texture maps are public-domain CC0 assets downloaded from
[Poly Haven](https://polyhaven.com/) through its public API.

- `corrugated_iron`: corrugated steel walls, bins, and metal roofs
- `concrete_floor_worn_001`: concrete slabs, silos, and gravel surfaces
- `clean_asphalt`: roads and parking areas
- `bitumen`: flat industrial roofing
- `leafy_grass`: planted and perimeter ground

Each set uses its diffuse, OpenGL normal, and roughness maps. Corrugated iron
also includes its metalness map. Files are kept at 1K for browser performance.
